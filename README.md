# Measurement before rankings

Public reproduction: https://www.kaggle.com/code/wuanxin/nfl-measurement-before-rankings

This development analysis uses only the 2023/2024 cohorts. The 2025 cohort is reserved. The tested Gauntlet summaries do not establish a predictive improvement over traditional measurements. See the notebook for selection limits, conditional intervals and the complete scientific claims.

Six derived figures and the identical public notebook source are mirrored here. No official raw data or per-player/per-frame tables are included. Run the notebook with the official NFL Big Data Bowl 2027 competition files on Kaggle.
